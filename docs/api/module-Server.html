Module: Server

Cyber Chat Terminal ana Express ve Socket.IO HTTP sunucusu. Güvenlik katmanı: Katı CSP, HSTS, Güvenlik Başlıkları, DoS/Abuse hız sınırlaması (HTTP rate limit), CSWSH ve CORS savunması ile Graceful Shutdown mekanizmalarını barındırır.
