Module: ClientSocketHandlers

İstemci tarafı Socket.IO olay dinleyicileri modülü. Sunucudan gelen durum değişiklikleri (node_status_change), yazıyor animasyonları (user_typing/stop), ECDH teklif/yanıtları (ecdh_offer/answer), şifreli paket teslimatı (receive_secure_packet), mesaj iptalleri (packet_revoked) ve kişi isteklerini (contact_request/response) karşılar.
