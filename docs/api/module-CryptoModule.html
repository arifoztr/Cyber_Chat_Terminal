Module: CryptoModule

Kriptografi ve Anahtar Yönetimi Modülü (v2 — ECDHE + KDF Ratchet). Web Crypto API kullanarak:

  • Kalıcı kimlik anahtarı (Identity Key, P-256 ECDH) — IndexedDB'de saklanır, sadece el sıkışmada kullanılır.
  • Oturum bazlı geçici anahtar çifti (Ephemeral Key, ECDHE) — her el sıkışmada yeniden üretilir, PFS sağlar.
  • KDF Zinciri (HKDF-SHA256 Ratchet) — her mesajda anahtar rotasyonu yaparak ileriye dönük gizlilik sağlar.
  • AES-GCM-256 (12-bayt IV) şifreleme / deşifreleme.
  • SHA-256 parmak izi ve Signal tarzı Güvenlik Numarası üretimi.
  • Bellek hijyeni: Uint8Array + fill(0) ile anahtar silme, sessionStorage'a sır yazılmaz.
