Module: CryptoModule

Kriptografi ve Anahtar Yönetimi Modülü. Web Crypto API kullanarak ECDH (P-256) anahtar çifti oluşturma, HKDF ile 256-bit AES anahtar türetimi (NIST SP 800-56A), AES-GCM (12-bayt IV) şifreleme ve deşifreleme, SHA-256 parmak izi (fingerprint) ve Signal tarzı Güvenlik Numarası (Safety Number) üretim ve doğrulama mekanizmalarını yönetir.
