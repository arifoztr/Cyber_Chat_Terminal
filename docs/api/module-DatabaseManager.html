Module: DatabaseManager

Veritabanı ve kalıcılık katmanı. Hem yerel SQLite3 (WAL modu) hem de uzaktaki Turso (libSQL) bulut veritabanını destekler. Bellek içi önbellekleme (in-memory state), debounce ile gecikmeli disk senkronizasyonu, ve otomatik çöp toplayıcı (TTL / GC) mekanizmalarını barındırır.
